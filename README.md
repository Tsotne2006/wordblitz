**პროექტის აღწერა:**
  პროექტი არის Wordle-ის მიერ ინსპირირებული, ხარ დროში შეზღუდული და შენი მისიაა 1 წუტში რაც შეიძლება მეტი სიტყვა გამოიცნო,
რათა დააგროვო ქულები(Score) და დროის გასვლის შემდეგ სურვილისამებრ შეინახო Scoreboard-ში.

  პროექტის გასაკეთებლად დამჭირდა დაახლოებით ~4 დღე.
გავწერე HTML, Css - დავიწყე ჩემით გაწერა, მაგრამ შიგადაშიგ თან დავიხმარე Ai (მითუმეტეს დასაწყისში საიტის დიზაინის იდეის მოსაფიქრებლად),
უმეტესი JS დაწერილია ჩემს მიერ მაგრამ პროცესის ასაჩქარებლად შიგადაშიგ გამოვიყენე AI.
საიტის Responsivenes(media min-max) სრულიად AI-s გავაკეთებინე ბოლოში.

index Page-ზე არის Rating სისტემა რომელიც დაკავშირებულია Discord Webhook-თან და გაშვების შემთხვევაში იგზავნება Discord სერვერზე. - ვიცი რომ ეს არის ძალიან ცუდი ხერხი ამის გასაკეთებლად
მაგრამ რეალურად ჩემი Backend ის აწყობა ცოტა დამეზარა რეალურ პროექტში ამას Backend ის უკან დავმალავდი და ისე გავაგზავნიდი მოთხოვნებს.

ინგლისური სიტყვების გადასამოწმებლად გამოვიყენე https://freedictionaryapi.com/, სადაც 8.5 მილიონზე მეტი სიტყვაა.
პროექტში ასევე მაქვს სიტყვების სია, რომელიც შედგება იმ არსებული Possible სიტყვებით რაც შეიძლება მომხმარებელს ამოუვიდეს გამოსაცნობად.

Scoreboard-ზე დამატებული ინფორმაცია არის ლოკალური და ინახება localstorage - ში

საიტი დაჰოსტილია Netlify-ზე და ჯერჯერობით არის live

დამატებითი კითხვების შემთხვევაში საიტის ბოლოს მითითებულია საკონტაქტო ინფორმაცია სადაც შეგიძლიათ დამიკავშირდეთ :)
